# Cloudreve v4.23.5

**首个由 [Dark-CC/cloudreve](https://github.com/Dark-CC/cloudreve) 发布的正式版本。**
First official release shipped from the [Dark-CC/cloudreve](https://github.com/Dark-CC/cloudreve) fork.

本版本聚焦后台管理界面的若干修复。自 v4.23.4 以来的全部变更如下。

This release focuses on fixes for the admin dashboard. Everything changed since v4.23.4 is listed below.

## 修复 / What's Fixed

- **后台邀请码弹窗表单布局修复**（`2e1d5d79`）：管理员面板新建邀请码时，弹窗内表单行的栅格布局错乱，现已恢复正常。
  *Invitation-code dialog: the form row grid inside the admin "new invitation code" dialog was broken and is now repaired (`2e1d5d79`).*
- **三处后台样式修复**（#7）：
  - `/admin/event`（活动记录）与 `/admin/abuse`（滥用举报）缺少与其他后台页面一致的 `Container` 包裹，导致标题与内容对不齐，现已统一。
  - 邀请码弹窗内的起止时间选择框由原生控件替换为 MUI X `DateTimePicker`，与其他对话框风格一致。
  - `/admin/settings?tab=vas` 手动调整积分时表单字段被压扁错位，现已恢复正常尺寸。
  *Three admin UI fixes (#7): the event and abuse pages now use the same `Container` wrapper as the rest of the dashboard, fixing misaligned headers and content; the invitation-code start/end time fields now use MUI X `DateTimePicker`; and the squashed form fields in the manual credit adjustment dialog are back to normal.*

## 升级 / Upgrade

**Docker / Docker Compose** — 只需换镜像：

```bash
docker pull ghcr.io/dark-cc/cloudreve:latest
```

或使用迁移脚本（自动备份 compose 文件、换镜像、重启）：

```bash
curl -sSL https://raw.githubusercontent.com/Dark-CC/cloudreve/baixiong/migrate.sh | sh -s -- /path/to/compose/dir
```

**二进制** — 从下方 [Downloads](#downloads) 下载对应平台压缩包，停止服务、替换二进制、重启即可。`data/` 目录（SQLite、上传文件、`conf.ini`）不受影响。跨小版本升级时 schema 迁移会在首次启动时自动执行，建议照常先备份。

## Downloads

- **服务端二进制**：Linux（amd64 / arm64 / armv5–v7 / loong64）、Windows（amd64 / arm64）、macOS（amd64 / arm64）、FreeBSD（amd64 / arm64），附 `checksums.txt` 校验文件。
- **Docker 镜像**：`ghcr.io/dark-cc/cloudreve:v4.23.5`、`ghcr.io/dark-cc/cloudreve:latest`、`ghcr.io/dark-cc/cloudreve:slim`（多架构 manifest）。
- **桌面端与 Android**：将随各自的发布通道（`desktop-v*` / `android-v*`）单独发布。
